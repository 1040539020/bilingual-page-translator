# Chrome Web Store Listing Draft

## Title

Bilingual Page Translator

## Short Description

Free open-source immersive web page translation with bilingual, translation-only, and hover modes.

## Detailed Description

Bilingual Page Translator is a free open-source immersive translation extension for reading foreign-language web pages. It preserves page structure where possible and lets users choose bilingual, translation-only, or hover reading modes.

The extension software is free under the MIT License. Users bring their own translation provider credentials, such as a DeepSeek API key, or connect a compatible custom translation endpoint. The project does not sell subscriptions, translation credits, or hosted proxy translation access.

Features:

- Immersive bilingual page translation
- Translation-only reading mode
- Hover-to-view translation mode
- Selected-text translation overlay with copy button
- Context menu and keyboard shortcut support
- Configurable source and target languages
- DeepSeek support with user-owned API keys
- Custom translation endpoint support
- Optional anonymous usage statistics, disabled by default

## Privacy Policy Draft

The extension processes page text only to provide translation features requested by the user or enabled by user settings. Text is sent only to the translation provider configured by the user. API keys are stored in browser extension storage. Anonymous usage statistics are disabled by default and are sent only after explicit opt-in. The extension does not sell personal data.
